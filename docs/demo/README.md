# Demo walkthrough

Open it locally in any browser, or publish it with GitHub Pages via `.github/workflows/demo-pages.yml` (one-time: Settings → Pages → Source: GitHub Actions). The site URL will be `https://amvishalrajoriya.github.io/job-applier/`.
