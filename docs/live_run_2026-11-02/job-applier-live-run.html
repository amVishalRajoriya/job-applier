What real postings taught the agent

The test portal never produced these cases. Real postings did, so I fixed each one and added a test for it.

Old but still open

Databricks and Stripe keep some roles listed for two years. The agent closed anything first posted over 60 days ago. Now a job that is still on the employer's own board stays open, with a note about its age.

"Any one of" skills

Razorpay asks for "any one of PHP, Python, Golang, Java or C++". The agent counted the five you don't need as gaps. Now Python alone satisfies it, and the score went from 70 to 84.

Preferred degree read as required

"Master's degree" under nice-to-have was treated as the minimum, and "Bachelor's or Master's" demanded a master's. Both now mean a bachelor's is enough.

"Contracts" read as a contract job

Stripe's AR Analyst post mentions billing contracts, and the agent marked it a contract role. It now needs a phrase like "contract role" or "contractor".

Cover letter blocked by a job title

For "Lead Security Engineer" the fact checker thought the letter claimed leadership and security skills. Naming the role you're applying for no longer counts as a claim.
